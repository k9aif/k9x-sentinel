What it watches

Two tracks, read every morning

Techniques are judged by a local model against the catalog. Dependencies need no model: if the lowest version k9-aif allows has a known, fixed vulnerability, Sentinel says which floor to raise.

Technique track

Threat research

New attack write-ups, OWASP and MITRE ATLAS releases, and agent-security researchers. Article text is treated as untrusted: the model has no tools, and its answer is checked against the catalog.

Dependency track

OSV advisories

Every package k9-aif declares. A deterministic check, no model: is the allowed floor affected by an advisory that has a fix?

The yardstick

The capability catalog

The list of every K9-AIF control, mapped to the OWASP Top 10s for LLM and agentic applications. It ships with the framework, so each verdict is judged against the version you run.

How it works

From a new attack to a closed gap

Read

Only new items, from public URLs. k9x Shield labels injection text in an article; it never hides it, or Sentinel would be blind to the attack it is reading about.

Judge

Each threat is compared with the catalog and given a verdict.

coveredpartialgap

Wake a person

Only gaps and partial gaps of at least medium severity go to a reviewer in K9X HIL. Everything else is recorded and visible here.

Close it

An approval becomes a private draft advisory or an issue. The maintainers ship the fix and update the catalog in the same commit.

Architecture

Sources, Sentinel, the framework, people

Sentinel is itself a K9-AIF application: Router, Orchestrators, Squads and Agents, governed by k9x Shield and Granite Guardian, with human review through the framework's own HIL path.

Rules of the watch

Advisory, never autonomous

A person decides

Sentinel finds and explains. It never changes code.

Private by design

A gap is an unpatched weakness in a public framework. Details stay behind sign-in; the demo shows open gaps as "under private review", and gaps go to draft advisories.

It uses what it protects

Built on K9-AIF and governed by it, so every safeguard Sentinel checks for is one it runs under.

Part of the K9X ecosystem

Built on K9-AIF

Sentinel keeps the framework's defences current. K9X SATAN attacks them to prove they hold, and K9X HIL is where its reviewers decide.
